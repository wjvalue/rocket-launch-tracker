# 🚀 火箭发射追踪 · Rocket Launch Tracker

单文件网页应用，追踪中国及全球火箭发射计划：下次发射倒计时、火箭型号档案（中文规格/照片/简介）、任务说明、月历、关注提醒与多来源人工核实入口。

**零依赖、零构建**——整个应用就是一个 `index.html`，双击即可使用。

## 功能

- **中国 / 全球双视图**：默认聚焦中国发射（含商业航天），一键切换全球
- **下次发射倒计时**：大号等宽倒计时，24 小时内自动变绿；发射窗口、机构、地点一览
- **发射详情**：任务说明（英文原文）、火箭照片与中文规格档案（长征全系列 + 朱雀/谷神星/双曲线/力箭/天龙/引力/捷龙/快舟等 30+ 型号）、生涯发射统计
- **月历视图**：中国 / 全球模式切换，绿点为中国发射、蓝点为其他，点击日期展开当天任务
- **筛选与搜索**：按机构、火箭型号、时间范围（7/30/90 天）与关键词
- **关注 + 提醒**：星标发射，T-30 / T-10 分钟浏览器通知（页面打开期间有效）
- **我的笔记**：每条发射可写中文解读，localStorage 自动保存
- **多来源确认**：一键跳转必应资讯、微博 ChinaSpaceflight、搜狗微信搜索（公众号解读）、知乎、B 站、维基百科发射列表
- **深色 / 浅色主题**：手动切换或跟随系统，首帧无闪烁
- **离线兜底**：API 限流或断网时自动回退本地缓存并提示

## 使用

直接双击 `index.html`，或任意静态服务器：

```bash
python3 -m http.server 8766
# 打开 http://localhost:8766/
```

开启维基百科补充清单（设置内）可弥补 LL2 对国内商业航天任务的遗漏（需能访问维基百科的网络环境）。

## 数据来源

- 结构化数据：[Launch Library 2（The Space Devs）](https://thespacedevs.com/)——官方发布聚合，30 分钟本地缓存
- 火箭照片：Wikimedia Commons 与 LL2 媒体库，失效自动回退占位图
- 中国发射精确窗口：通常提前数天见于各海事局航行警告（禁航区通告），页内提供直达入口

> 说明：中国发射预报常为日期级，精确时间请以官方发布与航行警告为准。微信公众号内容无法被自动抓取，详情页提供一键搜索入口供人工核实。
